Stap 1 — Plak deze code in je pagina

Zet de <div> op de plek waar je de widget wilt. Het <script>-tag mag onderaan je pagina staan.

<!-- Stroomprijs widget --> <div id="sv-widget"></div> <script src="https://stroomvoorspeller.nl/widget.js"></script>

Dat is alles. De widget laadt automatisch en toont de prijs voor het huidige uur.

Stap 2 — Aanpassen (optioneel)

Voeg data--attributen toe aan de div voor extra opties:

Attribuut Waarden Omschrijving
data-supplier average (standaard)
tibber · frank
energyzero · anwb
vandebron · zonneplan
easy		 Welke aanbieder-opslag meegerekend wordt. Bepaalt de prijs die je bezoekers te zien krijgen.
data-theme light (standaard)
dark		 Licht of donker kleurthema. Kies dark als je widget op een donkere achtergrond staat.
data-lang nl (standaard)
en		 Taal van de widget: Nederlands of Engels.
data-compact false (standaard)
true		 Compact-modus: toont alleen de huidige prijs en status, zonder goedkoopste-uur-rij.

Voorbeeld met aanpassingen:

<!-- Tibber-prijs, donker thema, compact --> <div id="sv-widget" data-supplier="tibber" data-theme="dark" data-compact="true" ></div> <script src="https://stroomvoorspeller.nl/widget.js"></script>

WordPress

Gebruik het blok Aangepaste HTML (in de blok-editor: + → Aangepaste HTML) en plak de twee regels daarin. De widget verschijnt direct op je pagina.

Let op: sommige WordPress-themes filteren <script>-tags in de editor. Gebruik in dat geval de Code-editor-weergave of voeg de script-tag toe via Uiterlijk → Theme-editor → footer.php.

Veelgestelde vragen

Is de widget gratis?

Ja, volledig gratis. Geen registratie, geen API-key, geen limieten. Wij vragen alleen dat je de "Bron: stroomvoorspeller.nl"-link zichtbaar laat staan.

Hoe vaak wordt de prijs bijgewerkt?

De data wordt elke 3 uur vernieuwd door onze server. De widget zelf haalt altijd de meest recente versie op bij het laden van je pagina.

Welke prijs toont de widget?

De officiële ENTSO-E day-ahead prijs voor het huidige uur, inclusief energiebelasting en btw. Met data-supplier kun je de opslag van een specifieke aanbieder meenemen.

Werkt de widget op mijn site?

De widget werkt op elke website die reguliere HTML ondersteunt: WordPress, Wix, Squarespace, statische sites, custom HTML. De enige vereiste is dat je browser JavaScript ingeschakeld heeft.

Kan ik de widget aanpassen aan mijn huisstijl?

De widget heeft zijn eigen scoped CSS zodat hij niet botst met je site-stijlen. Geavanceerde aanpassingen (eigen kleuren, lettertype) zijn mogelijk door de widget in een container met eigen CSS te zetten. Neem contact op via contactstroomvoorspeller@gmail.com voor maatwerk.

Zijn er privacybezwaren?

De widget doet twee GET-requests naar stroomvoorspeller.nl (voor prijsdata en instellingen). Er worden geen cookies geplaatst en geen persoonlijke gegevens verstuurd. Je hoeft de widget niet te melden in je cookieverklaring.

Vermeld ons ook even?

Wij zijn een onafhankelijk hobby-project zonder budget voor advertenties. Een vermelding of backlink helpt ons enorm om meer huishoudens met een dynamisch contract te bereiken. Zoiets als: "Stroomprijzen via stroomvoorspeller.nl" is al geweldig.
